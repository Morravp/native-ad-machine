# Installing the Chrome Extension

1. Open Chrome and go to `chrome://extensions`
2. Enable **Developer mode** (top-right toggle)
3. Click **Load unpacked**
4. Select the `chrome-extension` folder from this project
5. The extension icon (yellow circle) will appear in your toolbar

## First-time setup

Click the extension icon and then ⚙ Settings.
Enter your Railway app URL (e.g. `https://your-app.railway.app`) and click Save.

## How to use

1. Go to [Facebook Ads Library](https://www.facebook.com/ads/library/)
2. Search for any advertiser
3. You'll see a yellow **⊕ Save to Board** button appear on each ad card
4. Click it — it captures the ad text and image
5. Click the extension icon in your toolbar
6. Choose a board from the dropdown, add optional notes, and click **Save to Board**

## Notes

- You need to create boards first in your Ad Machine dashboard under **Swipe Files → Boards**
- The extension captures ad copy, headline, image, and the page URL
- Facebook's page structure changes occasionally — if buttons stop appearing, the extension may need an update to its CSS selectors
